COLLEGARE I DATI REALI
──────────────────────────────────────────────
Le due impostazioni stanno nelle prime righe di assets/rotta.js.

A. Prova veloce
   var RAPIDAPI_KEY = "la-tua-chiave";
   Funziona subito, ma la chiave è leggibile da chiunque apra il sorgente.

B. Proxy (consigliato per il sito pubblicato)
   var RAPIDAPI_KEY = "";
   var PROXY_URL = "https://rotta-api.gioriva.workers.dev/volo/";

   Worker Cloudflare, piano gratuito:

   export default {
     async fetch(req, env) {
       const code = new URL(req.url).pathname.split("/").pop();
       if (!/^[A-Z0-9]{3,8}$/i.test(code)) return new Response("[]", { status: 400 });
       const r = await fetch(
         `https://aerodatabox.p.rapidapi.com/flights/number/${code}?withLocation=true`,
         { headers: {
             "X-RapidAPI-Key": env.ADB_KEY,
             "X-RapidAPI-Host": "aerodatabox.p.rapidapi.com" } });
       return new Response(await r.text(), {
         status: r.status,
         headers: {
           "content-type": "application/json",
           "access-control-allow-origin": "https://www.gioriva.it",
           "cache-control": "public, max-age=60" } });
     }
   };

   ADB_KEY va inserita come variabile segreta nel pannello Cloudflare.

Senza nessuna delle due, la pagina resta in modalità dimostrativa
con sei voli simulati: AZ610, LH1922, NH209, FR8623, SQ355, VY6412.
